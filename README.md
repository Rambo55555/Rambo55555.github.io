# Rambo55555.github.io

Academic homepage built with [al-folio](https://github.com/alshedivat/al-folio).

## Main files to edit

- `_pages/about.md` — biography, affiliation, research interests
- `_bibliography/papers.bib` — publications in BibTeX
- `_pages/projects.md` — selected projects
- `_data/socials.yml` — GitHub, Scholar, email, CV and other links
- `_config.yml` — site-wide settings

The `al-folio-redesign` branch is intentionally minimal and keeps the previous static site untouched on `main` until the migration PR is merged.
